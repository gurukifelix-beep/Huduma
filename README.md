# Huduma Credit landing page

A responsive React and Vite landing page for Huduma Credit e-bike financing.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The WhatsApp and email links are configured in `src/App.jsx`. The 24-month plan deposit remains marked for confirmation because the supplied information lists both KSh 10,000 and KSh 15,000.
